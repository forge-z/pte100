# Gramática controlada

## Procedimento

Padrão recomendado:

```text
[Condição], VERBO NO IMPERATIVO + OBJETO + COMPLEMENTO + LIMITE.
RESULTADO ESPERADO.
```

Exemplo: `Se a pressão for menor que 200 kPa, feche a válvula V2. Confirme pressão de 0 kPa.`

## Descrição

Padrão recomendado:

```text
SUJEITO TÉCNICO + VERBO NA VOZ ATIVA + OBJETO OU ESTADO.
```

Exemplo: `O controlador registra a temperatura a cada 5 segundos.`

## Requisito

Padrão recomendado:

```text
AGENTE OU SISTEMA + MODAL + AÇÃO + CRITÉRIO.
```

Exemplo: `O sistema deve rejeitar uma senha com menos de 12 caracteres.`

## Coordenação

Coordene nomes e qualificadores quando a relação for clara. Separe ações executáveis, exceto quando forem simultâneas e a simultaneidade estiver marcada. Evite mais de uma camada de subordinação em instruções.

## Pontuação

Use ponto para encerrar uma instrução. Use dois-pontos para introduzir lista ou explicação diretamente vinculada. Parênteses não devem conter condição, risco ou requisito. Ponto e vírgula é aceitável em listas compactas, não para acumular passos.
