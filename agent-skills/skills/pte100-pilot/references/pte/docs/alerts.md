# Alertas

## Estrutura

Um alerta completo responde a quatro perguntas:

1. Qual é a gravidade?
2. Qual é o risco?
3. Qual consequência pode ocorrer?
4. Como a pessoa evita a consequência?

Exemplo:

> **ADVERTÊNCIA — Tensão elétrica**  
> O contato com os terminais energizados pode causar lesão grave. Desligue o disjuntor Q3 e confirme tensão de 0 V antes de remover a tampa.

## Posição

Alerta geral aparece antes do procedimento. Alerta específico aparece imediatamente antes do passo perigoso. Não coloque o alerta depois da ação nem o separe por uma quebra de página evitável.

## Taxonomia

Use apenas `PERIGO`, `ADVERTÊNCIA`, `CUIDADO` e `AVISO` no núcleo. Perfis regulados podem mapear outra taxonomia e devem registrar a autoridade externa. Não use `NOTA` para risco.

## Limites

O lint pode verificar palavra-sinal, posição e presença de elementos. A classificação real do risco exige análise de segurança. Uma frase clara não corrige uma avaliação de risco incorreta.
