# Política de localidades

O núcleo PTE-100 é compartilhado. Cada coleção declara uma etiqueta BCP 47, como `pt-BR`, `pt-PT`, `pt-AO` ou `pt-MZ`.

Um perfil de localidade pode definir ortografia, separadores numéricos, colocação pronominal, termos preferidos e convenções de data em prosa. Ele não pode reduzir clareza, remover um alerta nem mudar a força normativa.

A versão 0.1 fornece vocabulário inicial apenas para `pt-BR`. Isso é uma limitação de cobertura, não uma afirmação de prioridade. Perfis adicionais exigem mantenedores da localidade, corpus e revisão pública.

Não misture localidades dentro de uma unidade, exceto em citação, interface, nome legal ou exemplo comparativo devidamente marcado.
