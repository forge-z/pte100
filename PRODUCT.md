# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

delegated: Astro static site, deployed through GitHub Pages; the website is a temporary public landing page inside this repository.

## Users

Technical writers, documentation teams, translators, software and industrial teams, researchers, and people evaluating controlled technical Portuguese. They arrive from public communication channels and need to understand the project quickly before deciding whether to read, test, or contribute.

## Product Purpose

PTE-100 is an open proposal for controlled technical Portuguese. It reduces avoidable ambiguity, terminology variation, and structural inconsistency in technical documentation while supporting human readers, translation, linting, search, and AI retrieval. The temporary website's success is a visitor understanding the proposal and reaching the canonical repository or specification.

## Positioning

PTE-100 is an original Portuguese-first standard with its own rules, vocabulary, conformance levels, machine-readable contracts, and open governance. It is not a translation, official adaptation, or implementation of ASD-STE100.

## Operating Context

The canonical content is maintained in this repository: specification in `spec/`, rules in `rules/`, vocabulary in `vocabulary/`, examples in `examples/`, and the offline PTE-Lint MVP in `bin/` and `lib/`. GitHub is the source of truth for contribution, discussion, releases, and technical artifacts.

## Capabilities and Constraints

The website is a single-page, static, mobile-responsive landing page for initial public communication. It must link to the canonical GitHub repository and local project artifacts, avoid invented adoption, customer, performance, or certification claims, and state that v0.1 is a public proposal rather than a stable standard. No backend, authentication, CMS, or analytics is required for the first version.

## Brand Commitments

The name is PTE-100 — Português Técnico Essencial. The voice is clear, technical, open, and precise. The project is licensed under Apache-2.0 and must clearly state its independence from ASD-STE100.

## Evidence on Hand

The repository contains the v0.1 specification, 50-rule catalog, controlled vocabulary, before/after examples, procedure example, PTE-Lint MVP, schemas, governance documents, roadmap, and corpus methodology. There are no verified customer testimonials, adoption metrics, certification claims, or external case studies; the website must not fabricate them.

## Product Principles

- Explain the project with concrete examples before abstract claims.
- Keep the repository and specification as canonical sources.
- Distinguish the experimental v0.1 proposal from a stable or certified standard.
- Make the next action obvious: read, test, or contribute.
- Preserve technical accuracy and avoid claims not supported by repository evidence.

## Accessibility & Inclusion

The landing page must be keyboard navigable, responsive, readable with strong contrast, semantically structured, and usable without animation. The project is Portuguese-first, with the existing English overview linked as an informative alternative.
